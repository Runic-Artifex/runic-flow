# WebUIToolkit.MVVM.Flow

Wave A provides the frontend-neutral Flow foundation for .NET 10: validated logical keys,
typed outcomes, content descriptors and presentation leases, lifecycle contracts, exact-once
completion, deterministic clock helpers, and the internal content-session ownership kernel.

Public feature APIs remain in the flat namespaces `WebUIToolkit.MVVM.Navigation`,
`WebUIToolkit.MVVM.Dialogs`, `WebUIToolkit.MVVM.Operations`,
`WebUIToolkit.MVVM.Workflows`, and `WebUIToolkit.MVVM.Flow`.

The runtime is BCL-first. Dependency injection, logging, and options integration through
Microsoft.Extensions packages will be introduced by future adapters after their central
package versions are approved.

Publication remains subject to the repository's pending license decision.
